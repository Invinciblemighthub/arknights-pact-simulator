# 🛡️ 明日方舟契约模拟器 (Ark Pact Simulator)

一个专为《明日方舟》卫戍协议（赛季模式）打造的**单文件、纯本地配队推演沙盘**。

无需安装任何软件，无需配置 Node.js，**双击 HTML 文件即可在浏览器中运行**。你可以导入游戏数据，自由组合干员，系统会实时帮你推演当前阵容的盟约收益与叠层潜力。

> 💡 **提示**：我也会持续在赛季更新时，将最新的现成 Excel 表格上传到本仓库中（前提是我还记得的话）。如果我忘记了或者你想自己抓数据，可以直接查看下方的【方法二】。

## ✨ 核心特性

*   📦 **单文件免安装**：仅一个 `index.html` 文件，下载即用，跨平台兼容（Windows / macOS / 手机浏览器均可）。
*   📊 **无缝导入数据**：支持上传 `.xlsx` / `.csv` 格式的干员数据表。
*   ⚡ **多盟约互联筛选**：点击盟约标签瞬间过滤，鼠标悬停干员即可高亮其携带的所有盟约，轻松补齐羁绊。
*   ⚙️ **发动机网络分析**：基于干员特质（单次/持续叠加），自动区分**“已激活发动机”**与**“潜力发动机”**，并精准提示“还需补足几人”。
*   🎨 **明暗双主题**：内置护眼亮色与硬核暗色模式，自动记忆你的偏好。
*   🔒 **绝对安全**：所有计算均在浏览器本地完成，数据不会上传至任何服务器。

## 🚀 零基础：如何获取游戏数据？

如果你是第一次使用，手里没有现成的 Excel 表格，请根据你的需求，选择以下两种方法之一。

> 💡 **推荐使用电脑端 Chrome 或 Edge 浏览器操作**。

### 方法一：从官网抓取最新赛季数据

### 第一步：打开数据源网站
访问玩家整理的卫戍协议数据站：
👉 [https://squad-pool.com/arknights-pacts](https://squad-pool.com/arknights-pacts)

### 第二步：打开开发者工具（F12）
在网页上按下键盘的 **`F12`** 键（或者右键点击页面空白处，选择“检查 / Inspect”）。
在弹出的面板中，点击最上方的 **“网络” (Network)** 标签卡。

### 第三步：刷新网页抓取数据
在保持 F12 面板打开的情况下，**按 `F5` 刷新网页**。
此时，“网络”面板下方会快速闪过很多文件请求。在过滤框中输入 `data.js`，找到名为 [arknights-pacts-data.js?v=20261110-1](https://squad-pool.com/arknights-pacts-data.js?v=20261110-1) 的文件（如图所示）。

### 第四步：保存数据文件
点击找到的这个 `.js` 文件，在右侧弹出的面板中选择 **“响应” (Response)** 标签。
你会看到里面全是代码。**右键点击这些代码，选择“全选”**，然后复制。
在电脑上新建一个文本文件（`.txt`），把代码粘贴进去，并将文件名修改为 `arknights-pacts-data.js`（或者直接存为 `.txt` 也可以）。

### 第五步：转换为可导入的 Excel / CSV 表
由于本推演器目前直接读取的是 Excel 格式，你可以使用任意 AI 助手（如 ChatGPT / DeepSeek / Kimi）将刚才复制的代码一键转换为表格：

**将以下提示词 + 刚才复制的 JS 代码发给 AI：**
> “请将这份 JS 源码中 `ops` 数组里的干员数据提取出来，转换为 CSV 格式。列名必须为：干员,阶数,盟约标签,特质类型,普通效果(n),精锐效果(e)。其中 `盟约标签` 必须是带中括号的 JSON 格式（如 `["炎", "坚守"]`），严禁拆成两列。”
> 
> *（把刚才复制的代码粘贴在这里）*

拿到 AI 生成的 CSV 文本后，保存为 `.csv` 文件，或者直接用 Excel 另存为 `.xlsx` 文件。

### 第六步：导入推演器
现在，双击打开本项目的 `index.html`，将你刚刚保存的 `.xlsx` 或 `.csv` 文件拖入网页中，即可开始配队！

### 方法二：直接使用本仓库的现成数据

#### 第一步：打开本仓库主页
直接访问你当前所在的 GitHub 页面，无需离开本网站。

#### 第二步：找到并下载数据文件
在仓库的文件列表中，找到名为 **`ark-pack-data.txt`** 的文件。

#### 第三步：复制文件内容

#### 第四步：准备数据文件
在电脑上新建一个文本文件（`.txt`），把你刚才复制的代码粘贴进去（如果你接下来直接进行第五步，不保存也可以）。

#### 第五步：转换为可导入的 Excel / CSV 表
由于本推演器目前直接读取的是 Excel 格式，你可以使用任意 AI 助手（如 ChatGPT / DeepSeek / Kimi）将刚才复制的代码一键转换为表格：

**将以下提示词 + 刚才复制的 JS 代码发给 AI：**

拿到 AI 生成的 CSV 文本后，保存为 `.csv` 文件，或者直接用 Excel 另存为 `.xlsx` 文件。

## 📁 数据表格格式要求说明

本工具采用**数据驱动**架构，无论你用 AI 转换还是自己整理，最终导入的 Excel/CSV 必须满足：

*   **工作表名称**：系统会自动寻找名为 `干员143` 或 `干员` 的工作表。
*   **必须包含的列名（自动识别）**：
    *   `干员`（名字）
    *   `阶数`
    *   `盟约标签`（例如：`["炎", "坚守"]` 或 `炎,坚守` 均可）
    *   `特质类型`（作战能力 / 单次叠加 / 持续叠加 / 整备能力 / 特异化）
    *   `普通效果 (n)` / `精锐效果 (e)`
