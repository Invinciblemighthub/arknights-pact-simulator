# 🛡️ 卫戍协议推演器 (Ark Pact Simulator)

一个专为《明日方舟》卫戍协议（赛季模式）打造的**单文件、纯本地配队推演沙盘**。

无需安装任何软件，无需配置 Node.js，**双击 HTML 文件即可在浏览器中运行**。你可以导入游戏数据，自由组合干员，系统会实时帮你推演当前阵容的盟约收益与叠层潜力。

## ✨ 核心特性

*   📦 **单文件免安装**：仅一个 `index.html` 文件，下载即用，跨平台兼容（Windows / macOS / 手机浏览器均可）。
*   📊 **无缝导入 Excel**：支持直接上传官方/整理的 `.xlsx` 或 `.csv` 格式的干员数据大表（自动寻找“干员”Sheet页）。
*   ⚡ **多盟约互联筛选**：点击盟约标签瞬间过滤，鼠标悬停干员即可高亮其携带的所有盟约，轻松补齐羁绊。
*   ⚙️ **发动机网络分析**：基于干员特质（单次/持续叠加），自动区分**“已激活发动机”**与**“潜力发动机”**，并精准提示“还需补足几人”。
*   🎨 **明暗双主题**：内置护眼亮色与硬核暗色模式，自动记忆你的偏好。
*   🔒 **绝对安全**：所有计算均在浏览器本地完成，数据不会上传至任何服务器。

## 🚀 如何开始使用？

1. 在仓库右侧点击 **[Releases]** 下载最新的 `index.html` 文件（或直接下载仓库代码）。
2. 双击 `index.html` 用浏览器（推荐 Chrome / Edge）打开。
3. 将你的干员数据 Excel 文件拖入页面。
4. 开始配队推演！

*(首次打开需要联网，因为需要通过 CDN 加载 SheetJS 解析引擎。)*

## 📁 如何导入新赛季数据？

本工具采用**数据驱动**架构，赛季更新无需修改代码。只需更新你的 Excel 表格即可。

**表格格式要求：**
*   **必须包含的工作表**：名为 `干员143` 或 `干员`。
*   **必须包含的列名（自动识别）**：
    *   `干员`（名字）
    *   `阶数`
    *   `盟约标签`（例如：`["炎", "坚守"]` 或 `炎,坚守` 均可）
    *   `特质类型`（作战能力 / 单次叠加 / 持续叠加 / 整备能力 / 特异化）
    *   `普通效果` / `精锐效果`

## 🛠️ 技术栈

*   原生 HTML / CSS / JavaScript (无框架)
*   [SheetJS](https://sheetjs.com/) (用于浏览器端 Excel 解析)
*   CSS Variables (用于主题切换与状态渲染)
